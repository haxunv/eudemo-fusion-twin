# 演示物理模型与功率账本

数据类别为 `synthetic_demo`。几何和磁平衡来自本项目保留的 Bluemira / EU-DEMO 概念设计资产；热源分配、冷却回路、热阻和等离子体温度剖面属于显式演示假设。所有假设、单位、设计、平衡与场版本随 JSON 和 NPZ 导出。

## 功率定义

`power` 是名义有效热功率预算，单位 MW，不是由聚变反应率求得的聚变功率。`phase` 是无量纲负荷扫描位置：

```
load_fraction = 0.22 + 0.78 * phase
requested_thermal_MW = power * load_fraction
```

它没有秒单位，也不代表温度随真实时间的演化。`reference/rampup/sof/eof/rampdown` 是单独选择的源磁平衡快照，不能由动画播放速度推断装置放电时序。

演示热源分配：80% 为包层体积热源，20% 进入等离子体表面通道。表面通道中 65% 为核心辐射，剩余分离面功率按 70% SOL 辐射、3% 壁面粒子、27% 靶板粒子分配。靶板内外侧分配为 30/70%。这些比例用于构建自洽且可复现的演示工况，不是中子输运、光子输运或脱靶模型的计算结果。

账本要求：

```
requested_thermal_MW = absorbed_thermal_MW + unresolved_MW
absorbed_thermal_MW = surface_absorbed_MW + volume_absorbed_MW
surface_absorbed_MW = 18 * sum(q_vertex * sector_vertex_area)
```

顶点面积为相邻三角形面积的三分之一累加，与三角形平均顶点热流的面积积分等价。若磁平衡不能在目标区域解析出某侧打击点，该侧功率进入 `unresolved_MW`，不转移到其他面，也不计入冷却出口温升。界面会显示未解析功率。

## 受热面与打击点

受热面根据源几何生成配置中的 `blanket_panel_points` 和 `div_internal_boundary` 构建，并保留对应 CAD 部件来源与实际环向覆盖。网格只表示面向等离子体的表面，不包含实体背面、包层内部流道、歧管和扇区端盖。

这是轴对称分析表面，不能据此声称解析了三维倒角、连接缝或磁力线遮挡。CAD 显示网格与热分析网格各自承担几何展示和场采样职责。

打击点为源归一化磁通 `psi_n=1` 与偏滤器轮廓的下部交点。粒子热流采用 Eich 形状，演示上游宽度 `lambda_q=6 mm`、展宽 `S=2 mm`，结合磁通映射和入射角，在打击点附近 ±0.75 m 范围内归一化。`hotspot` 调整宽度，不能凭空增加该通道的总功率。辐射按壁面/偏滤器 90/10% 分配，再在各自面积上均匀沉积。

Eich 形状出处：[Eich et al., Physical Review Letters 107, 215001 (2011)](https://doi.org/10.1103/PhysRevLett.107.215001)。本演示使用合成宽度参数，不属于经验证的聚变装置预测。

## 温度、磁力线与体场

- 冷却回路采用氦比热 5200 J/(kg·K)，总质量流量 `3500 * flow` kg/s，包层/偏滤器回路按 85/15% 分配。出口温升使用同一账本的实际吸收功率；表面温度使用局部热流和简化热阻。
- 900°C 为界面演示阈值，不是材料合格判据。
- 磁力线使用所选源平衡的极向场和 `Bphi=fvac/R`，以环向角为自变量执行 RK4 三维轨迹积分；没有离散 TF 纹波和三维遮挡计算。
- 截面温度为由归一化磁通塑形的合成 keV 剖面；三维体场由该轴对称剖面回转采样。NanoVDB 和 IndeX 改变存储与可视化方式，不提高物理模型的有效性。
- 差值场为同一设计、同一平衡、同一负荷扫描位置下，当前工况减额定工况；两者几何采样位置一致。

## 验证范围

`tests/test_physics.py` 验证三角面积分、各功率通道闭合、打击点磁通残差、缺失打击点处理、出口温升、网格加密、字段版本和参数边界。`tests/test_compute.py` 验证 CPU/CUDA 一致性、磁力线方向与磁通漂移等。它们验证本演示实现的数值自洽，不验证真实反应堆运行安全或设计性能。
